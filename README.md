# Your Ways（仮称）— 聖書アプリ

紙の聖書を読むような画面で、聖書を読み、線を引き、気づきや祈りを残せる日本語アプリです。
意味がわからない箇所は、AIの先生「パウロ先生」にその場で質問できます。

> アプリ名は仮です。聖書の翻訳（口語訳）と開発技術（Web アプリ）も、いったん動く形にするために選んだもので、あとから差し替えられる作りにしてあります（[未確定の項目と、変える場所](#未確定の項目と変える場所)）。

## できること

### 中心の5機能

| 機能       | 内容                                                                     |
| ---------- | ------------------------------------------------------------------------ |
| 聖書を読む | 書と章を選ぶ・前後の章へ移動する・最後に読んだ箇所から再開する           |
| 線を引く   | 節を押して選び、金色のマーカーを付ける／外す                             |
| メモと祈り | 選んだ節に結びつけて保存する。節に結びつかない祈りも「ノート」から書ける |
| パウロ先生 | 選んだ節について、やさしい日本語で解説・対話する（Claude API）           |
| しおり     | 章や節に複数はさめる。「しおり」から続きや読み返したい箇所へ戻る         |

### 読みやすくするための機能

| 機能             | 内容                                                                                             | 場所                     |
| ---------------- | ------------------------------------------------------------------------------------------------ | ------------------------ |
| 文字の大きさ     | 小・中・大・特大                                                                                 | 読む画面の「表示」／設定 |
| ふりがな         | あり・なし                                                                                       | 同上                     |
| 縦書き           | 紙の聖書と同じく、右から左へ読み進む                                                             | 同上                     |
| 夜の配色         | 黒地にクリームの文字と金（同じ3色のまま）。昼・夜・端末に合わせる                                | 同上                     |
| さがす           | ことばをふくむ節を、聖書全体からさがす（旧約・新約でしぼれる）                                   | 「さがす」タブ           |
| オフライン       | 本文を端末に保存して、電波が無くても読む・さがす。ホーム画面に追加                               | 設定                     |
| 先生の答えを保存 | パウロ先生の答えを、その節のメモとして残す                                                       | 先生との対話             |
| バックアップ     | 線・メモ・祈り・しおりをファイルに書き出す／読み込む                                             | 設定                     |
| 線の一覧         | 線を引いた箇所を、聖書の順に読み返す                                                             | 「ノート」→「線」        |
| 読みはじめの案内 | 使い方と、はじめての人向けの読みはじめの候補                                                     | 初回に表示／設定         |
| 人物のイラスト   | 節を選ぶと、出てくる人物を小人ふうのイラストで表示。押すと、どんな人かを読める（41人）           | 節を選んだときの操作バー |
| 動画にする       | 選んだ箇所の言葉が順に現れる、縦長の短い動画を作って保存・共有する（端末の中だけで作成。音なし） | 同上                     |

SNS・公開・課金・ランキング・音声会話・アバター演出は入れていません。

## 動かし方

Node.js 22 以上が必要です。

```bash
npm install
cp .env.example .env   # パウロ先生を使うなら ANTHROPIC_API_KEY を書く
npm run dev            # 画面 http://localhost:5173 ／ API http://localhost:8787
```

| コマンド                            | すること                                                            |
| ----------------------------------- | ------------------------------------------------------------------- |
| `npm run dev`                       | 開発用に画面と API を同時に起動する                                 |
| `npm run build`                     | 型チェックをして、本番用の画面を `dist/` に作る                     |
| `npm start`                         | 本番用サーバーを起動する（`dist/` の画面と API を同じポートで配信） |
| `npm test`                          | 単体テスト                                                          |
| `npm run lint` / `npm run format`   | コードの検査／整形                                                  |
| `npm run build:bible -- <OSIS XML>` | 聖書本文データを作り直す                                            |

オフラインで読む仕組み（サービスワーカー）は、`npm run build` した本番の画面でだけ動きます。開発中（`npm run dev`）は使いません。

### パウロ先生（AI）の設定

- `ANTHROPIC_API_KEY` をサーバーの環境変数（`.env`）に設定します。API キーはブラウザには渡りません。
- 未設定でも、ほかの機能はすべて使えます（先生だけ「準備中」と表示されます）。
- モデルは `TEACHER_MODEL` で変更できます（既定は `claude-opus-5-5`）。
- 先生の人柄や答え方は [`server/teacher/prompt.ts`](server/teacher/prompt.ts) の文章で決めています。
- 使いすぎ防止として、同じ相手からの質問は10分あたり30回までに制限しています（[`server/config.ts`](server/config.ts)）。

画面だけを静的ホスティングに置くこともできます（その場合、先生は使えません）。画面と API を別の場所に置くときは、画面側に `VITE_API_BASE_URL`、API 側に `CORS_ORIGIN` を設定します。

## 構成

```
shared/                画面・サーバー・ビルドが共通で使うもの
  appInfo.ts           アプリ名・説明・地の色（ここを変えると題名やホーム画面の名前に反映）
  bible/               聖書の型・箇所の表記・ふりがなの扱い
    translations/      翻訳ごとの書名と章数（いまは口語訳だけ）
  teacher/contract.ts  パウロ先生の API の取り決め
scripts/
  build-bible.ts       OSIS（XML）→ アプリ用 JSON の変換
public/
  bible/kougo/         変換済みの本文（書ごとに1ファイル）と、検索用の search.json
  icons/               ホーム画面用のアイコン
pwa/                   ホーム画面への追加・オフライン対応
  vitePlugin.ts        index.html の置きかえ、manifest と sw.js の出力
  service-worker.js    サービスワーカーのひな形
server/                パウロ先生の API（Hono）。本番では画面も配信する
  teacher/             指示文（prompt）・本文の用意（passage）・中継（route）
src/
  app/                 画面の構成（ルーティング・タブバー）
  config/app.ts        先生の呼び名など、画面側の設定
  styles/tokens.css    色・文字・余白の定義（昼と夜）
  components/          どの機能からも使う部品（シート・ボタンなど）
  lib/                 保存の仕組み・日付・URL などの小道具
  features/            機能ごとのまとまり
    bible/             本文の読み込み・ふりがな表示
    reader/            読む画面（章の表示・節の選択・書と章の選択・縦書き）
    highlights/        線と、その一覧
    journal/           メモと祈り
    bookmarks/         しおり
    teacher/           パウロ先生との対話
    search/            さがす
    settings/          表示の設定（文字・ふりがな・組み方・配色）と設定画面
    offline/           端末への保存・ホーム画面への追加
    backup/            記録の書き出し・読み込み
    guide/             はじめての方への案内
    people/            人物の紹介とイラスト（people.ts に人物、chibi.ts に絵の描き方）
    video/             選んだ箇所の動画づくり（台本の計算と、描画・録画）
```

機能を足すときは `src/features/` にフォルダを足し、共通で使うものだけを `components/` や `lib/` に置きます。
記録を持つ機能は、データの形と計算（`…Model.ts`）と、保存・画面とのつなぎ（`…Store.ts`）に分けています。

### データの保存

- 線・メモ・祈り・しおり・表示の設定・最後に読んだ箇所は、端末のブラウザ（localStorage）に保存します。アカウントもサーバー側の保存もありません。
- 読み書きは [`src/lib/persistentStore.ts`](src/lib/persistentStore.ts) にまとめてあるので、同期を足すときはここを差し替えます。
- バックアップは、線・メモ・祈り・しおりを1つの JSON ファイルにまとめたものです。読み込みは「足す」だけで、端末にある記録は消しません。
- パウロ先生との会話は保存しません（アプリを開いている間だけ覚えています）。残したい答えは「メモに保存」で残せます。

### オフライン

- 本番の画面では、サービスワーカーが画面のファイルと、開いた書の本文を端末に覚えます。
- 設定の「本文を保存する」で、全66書と検索用データ（約16MB）をまとめて保存します。明朝体が入っていない端末（主に Android）では、聖書に出てくる文字の分の Web フォントも保存します。
- パウロ先生への質問には、通信が必要です。

## 聖書本文について

- 翻訳：口語訳聖書（日本聖書協会、新約 1954年・旧約 1955年）
- 出典：[seven1m/open-bibles](https://github.com/seven1m/open-bibles) の `jpn-kougo.osis.xml`（Public Domain と表示されているもの）
- 66書・31,087節。段落、詩の行分け、詩篇の表題、ふりがなを保ったまま変換しています。
- 変換時に直したのは、元データの誤植1か所（サムエル記下 19:32 の余分な「{」）だけです。
- 節の区切りは口語訳のとおりです（例：民数記 15:4-5 のような合併節、出エジプト記 22章の 3a・3b）。
- 検索は、本文の文字の並びがそのままふくまれるかで判断します（ふりがなや読みでは探しません）。

口語訳は日本では著作権の保護期間が満了したものとして広く扱われていますが、公開・配布の前に、利用条件を改めて確認してください。

作り直すには、上の XML を入手して次を実行します。

```bash
npm run build:bible -- path/to/jpn-kougo.osis.xml
```

## デザインの決まり

- 色は **クリーム・金・黒の3色だけ**。濃淡もこの3色の範囲で作り、青・赤・紫などの機能別カラーは足しません。夜の配色も、同じ3色の地と文字を入れ替えたものです（[`src/styles/tokens.css`](src/styles/tokens.css)）。
- 本文は明朝体。端末に明朝体が無いとき（主に Android）だけ Web フォント（しっぽり明朝）を読み込みます。
- 操作まわりの文字はゴシック体。
- 余白や字下げは、横書き・縦書きのどちらでも通じる書き方（inline / block）で指定しています。
