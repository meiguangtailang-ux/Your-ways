# Your Ways（仮称）— 聖書アプリ

紙の聖書を読むような画面で、聖書を読み、線を引き、気づきや祈りを残せる日本語アプリです。
意味がわからない箇所は、AIの先生「パウロ先生」にその場で質問できます。

> アプリ名は仮です。聖書の翻訳（口語訳）と開発技術（Web アプリ）も、いったん動く形にするために選んだもので、あとから差し替えられる作りにしてあります（[未確定の項目と、変える場所](#未確定の項目と変える場所)）。

## できること（初期版）

| 機能       | 内容                                                                                       |
| ---------- | ------------------------------------------------------------------------------------------ |
| 聖書を読む | 書と章を選ぶ・前後の章へ移動する・最後に読んだ箇所から再開する・ふりがなの表示を切り替える |
| 線を引く   | 節を押して選び、金色のマーカーを付ける／外す                                               |
| メモと祈り | 選んだ節に結びつけて保存する。節に結びつかない祈りも「ノート」から書ける                   |
| パウロ先生 | 選んだ節について、やさしい日本語で解説・対話する（Claude API）                             |
| しおり     | 章や節に複数はさめる。「しおり」から続きや読み返したい箇所へ戻る                           |

SNS・公開・課金・ランキング・音声会話・アバター演出は入れていません。

## 動かし方

Node.js 22 以上が必要です。

```bash
npm install
cp .env.example .env   # パウロ先生を使うなら ANTHROPIC_API_KEY を書く
npm run dev            # 画面 http://localhost:5173 ／ API http://localhost:8787
```

| コマンド                            | すること                                                            |
| ----------------------------------- | ------------------------------------------------------------------- |
| `npm run dev`                       | 開発用に画面と API を同時に起動する                                 |
| `npm run build`                     | 型チェックをして、本番用の画面を `dist/` に作る                     |
| `npm start`                         | 本番用サーバーを起動する（`dist/` の画面と API を同じポートで配信） |
| `npm test`                          | 単体テスト                                                          |
| `npm run lint` / `npm run format`   | コードの検査／整形                                                  |
| `npm run build:bible -- <OSIS XML>` | 聖書本文データを作り直す                                            |

### パウロ先生（AI）の設定

- `ANTHROPIC_API_KEY` をサーバーの環境変数（`.env`）に設定します。API キーはブラウザには渡りません。
- 未設定でも、読む・線・メモ・しおりはすべて使えます（先生だけ「準備中」と表示されます）。
- モデルは `TEACHER_MODEL` で変更できます（既定は `claude-opus-5-5`）。
- 先生の人柄や答え方は [`server/teacher/prompt.ts`](server/teacher/prompt.ts) の文章で決めています。
- 使いすぎ防止として、同じ相手からの質問は10分あたり30回までに制限しています（[`server/config.ts`](server/config.ts)）。

画面だけを静的ホスティングに置くこともできます（その場合、先生は使えません）。画面と API を別の場所に置くときは、画面側に `VITE_API_BASE_URL`、API 側に `CORS_ORIGIN` を設定します。

## 構成

```
shared/                画面とサーバーの両方が使うもの
  bible/               聖書の型・箇所の表記・ふりがなの扱い
    translations/      翻訳ごとの書名と章数（いまは口語訳だけ）
  teacher/contract.ts  パウロ先生の API の取り決め
scripts/
  build-bible.ts       OSIS（XML）→ アプリ用 JSON の変換
public/bible/kougo/    変換済みの本文（書ごとに1ファイル）
server/                パウロ先生の API（Hono）。本番では画面も配信する
  teacher/             指示文（prompt）・本文の用意（passage）・中継（route）
src/
  app/                 画面の構成（ルーティング・タブバー）
  config/app.ts        アプリ名・先生の呼び名などの設定
  styles/tokens.css    色・文字・余白の定義
  components/          どの機能からも使う部品（シート・ボタンなど）
  lib/                 保存の仕組み・日付・URL などの小道具
  features/            機能ごとのまとまり
    bible/             本文の読み込み・ふりがな表示
    reader/            読む画面（章の表示・節の選択・書と章の選択）
    highlights/        線
    journal/           メモと祈り
    bookmarks/         しおり
    teacher/           パウロ先生との対話
```

機能を足すときは `src/features/` にフォルダを足し、共通で使うものだけを `components/` や `lib/` に置きます。

### データの保存

線・メモ・祈り・しおり・最後に読んだ箇所は、端末のブラウザ（localStorage）に保存します。アカウントもサーバー側の保存もありません。
読み書きは [`src/lib/persistentStore.ts`](src/lib/persistentStore.ts) にまとめてあるので、同期やバックアップを足すときはここを差し替えます。
パウロ先生との会話は保存しません（アプリを開いている間だけ覚えています）。

## 聖書本文について

- 翻訳：口語訳聖書（日本聖書協会、新約 1954年・旧約 1955年）
- 出典：[seven1m/open-bibles](https://github.com/seven1m/open-bibles) の `jpn-kougo.osis.xml`（Public Domain と表示されているもの）
- 66書・31,087節。段落、詩の行分け、詩篇の表題、ふりがなを保ったまま変換しています。
- 変換時に直したのは、元データの誤植1か所（サムエル記下 19:32 の余分な「{」）だけです。
- 節の区切りは口語訳のとおりです（例：民数記 15:4-5 のような合併節、出エジプト記 22章の 3a・3b）。

口語訳は日本では著作権の保護期間が満了したものとして広く扱われていますが、公開・配布の前に、利用条件を改めて確認してください。

作り直すには、上の XML を入手して次を実行します。

```bash
npm run build:bible -- path/to/jpn-kougo.osis.xml
```

## デザインの決まり

- 色は **クリーム・金・黒の3色だけ**。濃淡もこの3色の範囲で作り、青・赤・紫などの機能別カラーは足しません（[`src/styles/tokens.css`](src/styles/tokens.css)）。
- 本文は明朝体。端末に明朝体が無いとき（主に Android）だけ Web フォント（しっぽり明朝）を読み込みます。
- 操作まわりの文字はゴシック体。

| 項目         | いまの状態                                                      | 変える場所                                                                                                                                                        |
| ------------ | --------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| アプリ名     | 仮に「Your Ways」                                               | [`src/config/app.ts`](src/config/app.ts) の `APP_NAME`、[`index.html`](index.html) の `<title>`                                                                   |

| 先生の呼び名 | パウロ先生                                                      | [`src/config/app.ts`](src/config/app.ts) の `TEACHER_NAME`、[`server/teacher/prompt.ts`](server/teacher/prompt.ts)                                                |
